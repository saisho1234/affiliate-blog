Nottaとは？概要・特徴

Notta（ノッタ）はAI音声認識を使ったクラウド型の文字起こし・議事録ツールです。リアルタイムでの録音文字起こしはもちろん、既存の音声・動画ファイルのアップロード文字起こし、Zoom・Teams・Google MeetへのBot自動参加など、会議に関わるあらゆる文字起こし作業を自動化できます。

Nottaでできること（主な機能一覧）

  • リアルタイム文字起こし（録音しながらテキスト化）
  • 音声・動画ファイルのアップロード文字起こし
  • Zoom・Teams・Google Meet へのBot自動参加
  • AI要約（会議の要点・アクションアイテムを自動抽出）
  • 話者識別（誰が何を話したか自動判別）
  • 42言語対応翻訳
  • PDF・Word・TXT・SRTエクスポート
  • Notion・Slack・Google Drive連携

Nottaの特徴は「初期費用ゼロ・クレカ不要・すぐ始められる」点です。ブラウザからアカウント登録するだけで、5分後には最初の文字起こしを体験できます。まずは詳細なレビューを読みたい方はNotta評判・口コミレビューもご参照ください。

無料登録方法（3ステップ）

Nottaへの登録は3ステップ・約2分で完了します。クレジットカードの登録は不要です。

ステップ1：公式サイトにアクセスしてアカウント作成

notta.aiにアクセスし、「無料で始める」ボタンをクリックします。登録方法は以下の3つから選べます。

  • メールアドレスで登録：メールアドレスとパスワードを入力し、確認メールのリンクをクリック
  • Googleアカウントで登録：「Googleでサインアップ」をクリックし、使用するGoogleアカウントを選択
  • Appleアカウントで登録（iOSの場合）

最も手軽なのはGoogleアカウントで登録する方法です。ボタン1クリックで登録が完了します。

ステップ2：ダッシュボードを確認する

登録完了後、自動的にNottaのダッシュボードが表示されます。画面上部に「今月の残り時間：120分」と表示されていれば登録成功です。

左サイドバーには「録音」「アップロード」「会議Bot」「設定」などのメニューが並んでいます。各機能へのアクセスはすべてここから行います。

ステップ3：最初の文字起こしを試してみる

ダッシュボード中央の「録音を開始」ボタンをクリックすると、すぐにリアルタイム文字起こしが始まります。試しに何か話しかけると、画面上にリアルタイムでテキストが表示されます。これで登録完了・使用開始です。

PC版の使い方（ブラウザ）

PCではブラウザからnotta.aiにアクセスして使います。Chrome・Edgeを推奨します。PCならではの2つの主要な使い方を紹介します。

PC版 使い方①：リアルタイム録音で文字起こし

  1. notta.aiにログインし、ダッシュボードを開く
  2. 左メニューまたは中央の「録音を開始」ボタンをクリック
  3. マイクのアクセス許可を求められたら「許可」をクリック
  4. 話すとリアルタイムでテキストが表示される
  5. 録音を停止するには「停止」ボタンをクリック
  6. 停止後、文字起こしテキストが保存され、AI要約の生成も開始される

ポイント：PCの内蔵マイクよりも外付けのUSBマイクやヘッドセットを使うと、文字起こし精度がさらに上がります。

PC版 使い方②：音声・動画ファイルをアップロードして文字起こし

  1. ダッシュボードの「ファイルをアップロード」またはドラッグ&ドロップエリアにファイルをドロップ
  2. 対応形式：MP3・WAV・M4A・AAC・FLAC・OGG・MP4・MOV・AVI・WMV など
  3. ファイルサイズ上限：1GB（Proプランの場合）
  4. アップロード完了後、自動で文字起こしが開始される（処理時間：音声1分あたり約15〜30秒）
  5. 文字起こし完了後、テキストが表示される

過去の会議録音・インタビュー音声・セミナー動画など、蓄積した音声データを一括で文字起こしするのに最適な使い方です。

PC版 使い方③：Zoom・Teams・Google Meet のBot連携

オンライン会議の議事録作成を完全自動化できる、Nottaの最も強力な機能です。

  1. Nottaダッシュボードの左メニュー「会議Bot」をクリック
  2. 使用する会議ツール（Zoom / Teams / Google Meet）を選択
  3. 「カレンダーを連携」でGoogleカレンダーまたはOutlookカレンダーを連携（スケジュールされた会議に自動Bot参加）、または「今すぐBotを招待」で会議URLを手動入力
  4. Nottaのボットが会議に参加し、自動で録音・文字起こしを開始
  5. 会議終了後、文字起こしとAI要約が自動生成される
読者からの質問
Notta BotがZoom会議に参加したら、他の参加者にはどう見える？
小田 健真（筆者）
「Notta Bot」という名前の参加者として表示されます。事前に参加者へ「議事録作成のためBotが入ります」と伝えておくと丁寧です。ボットはカメラ・マイクはオフで、録音のみ行います。

スマホアプリの使い方

Nottaのスマホアプリ（iOS・Android対応）は、対面会議・インタビュー・外出先での録音に最適です。

アプリのインストール

  • iPhone（iOS）：App Storeで「Notta」を検索してインストール
  • Android：Google Playで「Notta」を検索してインストール

インストール後、登録済みのアカウントでログインします。PC版で作成したデータはすべてスマホアプリでも確認できます。

スマホアプリ 使い方①：リアルタイム文字起こし

  1. アプリを起動し、ホーム画面の「録音」ボタン（赤いマイクアイコン）をタップ
  2. マイクへのアクセス許可を「許可」でOK
  3. 話すとリアルタイムでテキストが画面下に表示される
  4. 停止するには「停止」ボタンをタップ
  5. AI要約が自動生成されて保存される

対面会議での活用ポイント：テーブルの中央にスマホを置き、録音を開始します。話者識別機能が自動で誰の発言かを判別します。

スマホアプリ 使い方②：過去の録音ファイルをアップロード

  1. アプリのホーム画面下部「追加」または「+」ボタンをタップ
  2. 「ファイルからインポート」を選択
  3. スマホのファイルアプリまたは写真ライブラリから音声・動画ファイルを選択
  4. アップロード後、自動で文字起こしが開始される
読者からの質問
スマホで録音中にアプリを閉じたり画面をオフにしても大丈夫？
小田 健真（筆者）
バックグラウンド録音に対応しているので、画面をオフにしても録音は続きます。ただしアプリを完全に終了すると停止するので注意。画面ロックのまま録音継続できるのはとても便利です。

議事録の作成・編集・共有方法

文字起こしが完了したら、次は議事録として整える作業です。NottaならAI要約→手動修正→エクスポートの流れで、プロ品質の議事録が数分で完成します。

AI要約で自動的に要点を抽出する

  1. 文字起こし完了後の画面で「AI要約」タブをクリック（またはタップ）
  2. Nottaが自動で会議の「要点」「アクションアイテム」「決定事項」を箇条書きで生成
  3. 生成された要約をそのままコピーするか、さらに編集して使用

文字起こしテキストを手動で修正する

誤認識された専門用語・固有名詞は手動で修正できます。

  1. 文字起こしテキスト上で修正したい箇所をダブルクリック（PC）またはタップ（スマホ）
  2. 編集モードになるので正しいテキストに修正
  3. Enterキーまたは「保存」で確定（自動保存されます）

また、話者名のリネームも可能です。「話者1」→「山田さん」のように変更することで、より分かりやすい議事録になります。

翻訳機能の使い方

Nottaの翻訳機能を使えば、英語会議の文字起こしをワンクリックで日本語訳できます。42言語に対応しており、グローバルな会議での議事録作成が格段に楽になります。

翻訳の手順

  1. 翻訳したい文字起こしデータを開く
  2. 画面上部またはサイドパネルの「翻訳」ボタンをクリック
  3. 翻訳先の言語を選択（英語→日本語、日本語→英語など）
  4. 「翻訳を開始」をクリックすると、数秒〜数十秒で翻訳が完了
  5. 翻訳後のテキストは元の文字起こしと並べて表示されるか、翻訳のみ表示を切り替えられる

翻訳機能の活用シーン

  • 英語会議→日本語議事録：グローバルミーティングの内容を日本語チームに共有
  • 日本語会議→英語議事録：海外拠点・外国人メンバーへの共有
  • 多言語対応：中国語・韓国語・フランス語・ドイツ語など42言語に対応

よくある質問（FAQ）

Nottaの無料登録はどうやってするの？
notta.aiにアクセスし、メールアドレスまたはGoogleアカウントで登録するだけです。クレジットカードの登録は不要で、登録後すぐに月120分の無料文字起こしが使えます。
NottaはPCとスマホどちらでも使える？
はい、どちらでも使えます。PCはブラウザ（Chrome・Edge推奨）でアクセス、スマホはApp Store（iOS）またはGoogle Play（Android）からアプリをインストールして使います。データはクラウドで同期されます。
Nottaで音声ファイルをアップロードして文字起こしする方法は？
ダッシュボードの「ファイルをアップロード」ボタンをクリックし、MP3・WAV・M4A・MP4・MOVなどの音声・動画ファイルを選択するだけです。アップロード後、自動で文字起こしが開始されます。
NottaのZoom連携はどうやって設定する？
Nottaダッシュボードの「会議Bot」→「Zoom連携」からZoomアカウントを連携します。連携後は会議URLを入力するか、Googleカレンダーと連携してスケジュールされた会議にBotが自動参加します。
Nottaの文字起こし結果を議事録として編集・共有する方法は？
文字起こし完了後、テキスト上をクリックして直接編集できます。「AI要約」ボタンで会議の要点・アクションアイテムを自動抽出し、PDF・Word・TXT形式でダウンロードするか、Notion・Slackに直接送信できます。
Nottaの翻訳機能はどう使う？
文字起こし完了後、画面上部の「翻訳」ボタンをクリックし、翻訳先の言語を選択するだけです。42言語に対応しており、英語→日本語・日本語→英語などワンクリックで翻訳されます。
スマホアプリでリアルタイム文字起こしするには？
Nottaアプリを起動し、ホーム画面の「録音」ボタン（マイクアイコン）をタップすると、その場でリアルタイム文字起こしが開始されます。話しながら画面上にテキストが表示されます。
Nottaの文字起こし結果はどの形式で保存・出力できる？
PDF・Word（DOCX）・TXT・SRT（字幕形式）でエクスポートできます。また、Notion・Slack・Google Driveへの直接送信にも対応しています。
話者識別機能はどうやって使う？
Nottaは自動で話者を識別し、「話者1」「話者2」のように区別して文字起こしします。文字起こし完了後に話者名を手動でリネーム（例：「山田さん」「田中さん」）することもできます。
Nottaの無料プランでできることとできないことは？
無料プランでできること：月120分の文字起こし・リアルタイム文字起こし・ファイルアップロード・話者識別・AI要約・PDF/TXTエクスポート。制限されること：月120分超の文字起こし・一部のZoom/Teams Bot連携機能（Proプランで解除）。
