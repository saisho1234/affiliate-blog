DeepLとは？

★★★★☆ 4.4 / 5 （編集部評価）

DeepLは2017年にドイツのケルンで創業されたDeepL SE（旧Linguee GmbH）が開発したAI翻訳サービスです。ニューラルネットワークを活用した機械翻訳（NMT）の中でも特に「文脈の理解」と「自然な表現」に強みを持ち、公開直後から世界中のプロ翻訳者・研究者・ビジネスパーソンの間で話題となりました。

DeepLが選ばれる理由

従来の翻訳ツールは単語ごとの置き換えに近い直訳になりがちでしたが、DeepLは文全体の意味・トーン・文脈を読み取り、ネイティブに近い自然な表現を出力します。たとえば「It's raining cats and dogs.」のような慣用表現も、ただ直訳するのではなく「土砂降りだ」と意訳できるレベルです。

2026年現在、DeepLは33言語以上に対応し、日本語・英語・ドイツ語・フランス語・スペイン語・中国語など主要言語での翻訳精度は業界トップクラスと評価されています。無料版から利用を始められるため、まず試してから課金判断できる点も人気の理由です。

DeepL無料版の制限をわかりやすく解説

「DeepL翻訳 無料 制限」について詳しく知りたい方のために、無料版の制約を整理します。無料版はアカウント登録なしですぐ使えますが、以下の制限があります。

1回あたり最大1,500文字 Webブラウザ版で1回に入力できるのは1,500文字まで。それを超えると文字が自動カットされます。長文レポートや書籍の翻訳では複数回に分ける手間が発生します。
ファイル翻訳：月3件まで Word・PowerPoint等のファイルを月3件まで翻訳可能。ただしPDFには対応していません。月に数件以上ファイルを翻訳する方にはすぐ上限に達します。
用語集：1件まで 専門用語・固有名詞の辞書（用語集）は1件しか登録できません。複数のプロジェクトで用語を使い分けたい場合はProが必要です。
データプライバシーの制限 無料版では入力したテキストがDeepLの品質改善に使われる場合があります。個人情報・機密情報・社外秘文書の翻訳には必ずProプランを使用してください。

無料版の制限まとめ: 1,500文字/回・ファイル月3件・用語集1件・PDF非対応・データ学習あり。「仕事で毎日翻訳する」「PDFを翻訳したい」「機密情報を扱う」のいずれかに当てはまる場合はProプランへのアップグレードを推奨します。

無料版の制限について詳しくはDeepL「上限に達しました」の解除方法をご覧ください。

DeepLの使い方（基本操作）

DeepLの操作はとてもシンプルです。主な使い方を4パターンに分けて解説します。

1. Webブラウザから翻訳する

deepl.comにアクセスし、左側のテキストボックスに翻訳したい文章を貼り付けるだけで、右側に翻訳結果がリアルタイムで表示されます。言語は自動検出されますが、手動で指定することも可能です。翻訳結果はクリックで代替表現に変更でき、文脈に合ったベストな訳語を選べるのがDeepLならではの特徴です。

2. デスクトップアプリを使う

Windows・macOS向けのデスクトップアプリをインストールすると、ショートカットキー（Ctrl+C+C など）でどこからでも瞬時に翻訳できます。ブラウザを開く手間なく、メールやWord作業中でもシームレスに翻訳を呼び出せる点が便利です。

3. ファイルをまるごと翻訳する

Word・PowerPoint・PDFなどのファイルを直接アップロードして、書式を保持したまま翻訳ファイルをダウンロードできます。長文レポートや資料の翻訳に非常に有効で、手動でのコピペ作業が不要になります（Pro版推奨）。

4. 用語集（グロッサリー）を登録して精度を上げる

よく使う専門用語や固有名詞を「用語集」に登録しておくと、翻訳結果に一貫して反映されます。たとえば自社サービス名・製品名・業界特有の訳語などを登録することで、毎回手直しする手間を省けます。Pro版では複数の用語集を使い分けることも可能です。

DeepL APIとは？

DeepL APIは、DeepLの翻訳機能を外部システムやアプリに組み込むためのプログラムインターフェース（API）です。開発者向けのサービスで、自社の業務システム・Webサービス・モバイルアプリに翻訳機能を追加できます。

DeepL API Free vs Pro

DeepL API Freeは月50万文字まで無料で利用可能ですが、リクエスト数の上限や商用利用の制限があります。個人開発・プロトタイプ作成には十分です。

DeepL API Proは文字数の大幅な拡張・優先処理・データの即時削除・SLAが適用された商用利用向けプランです。月間数百万文字以上を翻訳するサービスへの組み込みに適しています。

APIの利用にはトークン（APIキー）の発行が必要で、DeepLのアカウント設定から取得できます。Python・JavaScript・Javaなど主要言語向けの公式SDKも提供されており、数行のコードでDeepLの翻訳エンジンを呼び出せます。

1. 文字数制限なしで翻訳し放題 無料版の1回1,500文字制限がなくなり、ビジネス文書や論文を気にせず翻訳できます。Advancedプラン以上なら月間翻訳文字数も無制限です。
2. ファイル丸ごと翻訳（PDF・Word・PowerPoint対応） レイアウトを保ったまま翻訳。報告書やプレゼン資料の翻訳作業が大幅に短縮されます。無料版では非対応のPDF翻訳もProなら対応しています。
3. 用語集（グロッサリー）でブレない翻訳 専門用語や社内用語を登録し、一貫した翻訳品質を維持できます。Advancedプランでは最大2,000件の用語集が登録可能です。
4. セキュリティ強化（翻訳データ非保存） Pro以上では翻訳テキストがサーバーに保存されず、AIの学習データにも利用されません。機密文書・契約書・個人情報を含む文章も安心して翻訳できます。
5. チーム共有・API連携 Advanced以上ではチームメンバーとアカウント共有が可能。API連携で社内システムへの翻訳機能の組み込みや業務自動化も実現できます。

DeepLが特に優れているシーン

ビジネスメール・契約書 フォーマルなトーンを保ちながら自然な英語に翻訳できます。取引先への英語メール作成や、海外からの契約書の内容確認に最適です。
技術文書・マニュアル 専門用語を用語集に登録することで、一貫性のある翻訳が可能です。エンジニアリング・IT分野のドキュメント翻訳での評価が特に高いです。
論文・学術文章 英語論文の内容把握や、日本語レポートの英文化に活用できます。ニュアンスを保った高精度な翻訳は研究者からも高く評価されています。
Webコンテンツ・ブログ翻訳 海外記事のリサーチ・多言語でのコンテンツ展開を効率化。書式を保ったまま翻訳できるため、WordPress等への貼り付けも容易です。
ECサイト・商品説明文 自然な商品説明文の翻訳や、海外向けECサイトの多言語化に活用されています。用語集機能でブランドの表記を統一できます。
海外ニュース・メールの読解 受信した英語・ドイツ語・フランス語などのメールや記事を素早く日本語で確認する「受信翻訳」用途でも非常に便利です。

DeepL Proがおすすめな人・無料版で十分な人

DeepL Proがおすすめな人

  • 週に10回以上翻訳する人： 1,500文字の制限に頻繁に引っかかるため、Starterプランで制限を解除すると作業効率が大幅に向上します
  • 機密文書を扱うビジネスユーザー： Pro版はデータが即時削除されるため、契約書・社内文書・個人情報を含む文章も安心して翻訳できます
  • PDFや大量ファイルを翻訳する人： 無料版はPDF非対応、月3件まで。Proなら書式を保ったままPDFを翻訳でき、月5件以上のファイル翻訳が可能です
  • 専門用語を統一したい人（用語集機能）： Advancedプランでは2,000件の用語集を登録でき、製品名・ブランド名を常に一貫した表現で翻訳できます
  • 海外クライアントと頻繁にやり取りするフリーランス： 英語メール・提案書・請求書などのビジネス文書を自然な英語で素早く作成できます

DeepL無料版で十分な人

  • 短い文章を時々翻訳するだけの人： 月に数回・1,500文字以内の翻訳なら無料版で十分対応できます
  • 学習・勉強目的の翻訳： 英語の勉強や海外ニュースを読むための翻訳なら無料版で問題ありません
  • 対応言語がDeepLにない場合： タイ語・ヒンディー語・アラビア語などはDeepLが非対応のため、Google翻訳を活用しましょう
  • 音声翻訳・リアルタイム会話翻訳が必要な場合： DeepLは音声非対応のため旅行・接客用途ではGoogle翻訳が向いています

よくある質問（FAQ）

Q1. DeepL Proは月いくらですか？
2026年7月時点の税込価格は、Starterプランが年払いで月換算約1,056円〜、Advancedプランが月換算約3,564円〜、Ultimateプランが月換算約7,700円〜です。月払いプランはやや割高になります。最新の正確な価格はDeepL公式サイトをご確認ください。
Q2. DeepL無料版の制限は何ですか？
無料版は1回の翻訳で入力できる文字数が1,500文字まで、翻訳できるファイルは月3件まで（PDFは非対応）、用語集は最大1件までとなっています。また、入力テキストがDeepLの品質改善に利用される場合があるため、機密情報の翻訳にはProプランを推奨します。
Q3. DeepLとGoogle翻訳どちらが精度高いですか？
文脈を考慮した自然な翻訳精度ではDeepLが優れているとされています。特に英語・ドイツ語・フランス語などヨーロッパ言語での差が顕著です。ただしGoogle翻訳は対応言語数が100以上と圧倒的に多く、音声翻訳や旅行時の即時翻訳ではGoogle翻訳が有利な場面もあります。
Q4. DeepLは日本語に対応していますか？
はい、DeepLは日本語に対応しています。英日・日英翻訳の品質は非常に高く評価されており、ビジネス文書・技術文書・学術論文の翻訳にも広く活用されています。
Q5. DeepL Proはいつでも解約できますか？
はい、DeepL Proはアカウント設定の「サブスクリプション」メニューからいつでもキャンセル手続きが可能です。月払いプランは翌月以降の更新が止まります。年払いプランの場合は残存期間の返金対応は原則ないため、契約前に十分ご検討ください。
Q6. DeepL APIとは何ですか？
DeepL APIは、DeepLの翻訳エンジンを自社アプリやシステムに組み込むためのインターフェースです。無料枠（API Free）では月50万文字まで翻訳可能で、それを超えると有料のAPI Proプランへの切り替えが必要です。Python・JavaScript等の公式SDKが提供されており、開発者が手軽に組み込めます。
Q7. DeepLでPDFを翻訳できますか？
PDFの翻訳はDeepL Proプラン（Starter以上）でのみ対応しています。無料版ではWordやPowerPointなどの一部形式のみ対応しており、PDFは非対応です。Proプランでは書式を保持したままPDFを翻訳したファイルをダウンロードできます。
Q8. DeepLはオフラインで使えますか？
DeepLのWebサービスおよびデスクトップアプリは、翻訳処理をクラウドで行うためインターネット接続が必須です。完全オフラインの翻訳ツールが必要な場合は、オフライン対応の別ツール（Microsoft Translatorのオフラインモード等）を検討してください。
Q9. DeepL StarterとAdvancedの違いは？
Starterは個人利用向けの入門プランで、文字数制限・ファイル翻訳件数・用語集数に上限があります。Advancedはビジネス利用を想定した設計で、用語集の件数が増え、ファイル翻訳件数も拡張されます。また、Advancedからはチームでの共有利用（複数シート追加）にも対応しています。日常的にDeepLを仕事で使う方にはAdvancedが最もコスパに優れたプランです。
Q10. DeepLは安全ですか？機密文書に使えますか？
DeepL Proプランでは、翻訳後すぐにテキストデータが削除され、AIの学習データとして利用されないことがプライバシーポリシーに明記されています。機密文書・個人情報・医療情報を含む文章を扱う場合は必ずProプランを利用し、DeepLの最新の利用規約・プライバシーポリシーを確認の上ご使用ください。
Q11. DeepLの翻訳精度はどのくらいですか？
DeepLはニューラルネットワークを活用したAI翻訳で、特に英語・ドイツ語・フランス語・日本語などの主要言語において業界トップクラスの精度と評価されています。単語の置き換えではなく文全体の文脈を読み取り、ネイティブに近い自然な表現を生成します。ビジネスメール・論文・技術文書の翻訳で特に高い評価を受けており、プロの翻訳者が下訳ツールとして採用するケースも増えています。
Q12. DeepLは無料で使えますか？
はい、DeepLは無料で利用できます。ブラウザからアカウント登録なしでもすぐに使え、1回の翻訳で最大1,500文字・月3件までのファイル翻訳（PDF非対応）が可能です。さらに高い上限や、PDFの翻訳・データの即時削除が必要な場合はDeepL Proプラン（年払いで月換算約1,056円〜）へのアップグレードをご検討ください。
Q13. DeepL無料版はいつ制限に達する？
無料版の1,500文字制限は、A4用紙約1枚分のテキストに相当します。英語メール数通・短い記事1本程度ならすぐには上限に達しませんが、報告書・論文・長い契約書などを翻訳しようとするとすぐに制限に引っかかります。目安として、日常的に1日2〜3回以上翻訳する方、またはWordやPDFファイルを月4件以上翻訳する方は、Proプランへのアップグレードを検討する価値があります。詳しくはDeepL「上限に達しました」の解除方法をご確認ください。
Q14. DeepL Proの解約方法は？
DeepL Proの解約は、DeepLアカウントにログイン後、右上のアカウントメニュー → 「サブスクリプション」→「プランをキャンセル」から行えます。月払いプランは翌月の更新が止まり、解約月末まで利用できます。年払いプランはキャンセル手続き後も契約期間終了まで使用可能ですが、中途解約による返金は原則ありません。年払い契約前に月払いで1〜2ヶ月試してから切り替えるのがおすすめです。
Q15. DeepL Pro StarterとAdvancedはどちらがおすすめ？
個人利用・副業レベルであればStarter（月約1,056円〜）、仕事でDeepLをメイン翻訳ツールとして使うならAdvanced（月約3,564円〜）がおすすめです。最大の違いは「翻訳文字数（Starterは月100万文字・Advancedは無制限）」「ファイル翻訳件数（Starter月5件・Advanced月20件）」「用語集数（Starter1件・Advanced最大2,000件）」の3点です。フリーランス翻訳者・ライター・海外取引のある方は最初からAdvancedを選ぶと費用対効果が高くなります。
Q16. DeepLは法人契約できる？
はい、DeepLは法人向けのプランも提供しています。AdvancedおよびUltimateプランでは、チームシートの追加によって複数の社員が同一アカウントでDeepL Proを利用できます。請求書払い・一括請求・セキュリティ要件への対応については、DeepLの法人向けお問い合わせページから直接問い合わせることが可能です。企業向けに大規模導入をご検討の場合は、DeepL for Teamsプランも確認してみてください。
Q17. DeepL WriteとDeepL翻訳の違いは？
DeepL翻訳は異なる言語間の翻訳ツールですが、DeepL Writeは同一言語内での文章改善ツールです。たとえば英語文章を「よりフォーマルに」「より自然に」「文法を修正して」といった指示で改善できます。英語ネイティブでないユーザーが書いた英語メール・レポートを洗練された表現に直す用途に向いています。2026年現在、英語・ドイツ語に対応しており、DeepL Proの契約に含まれています。翻訳後の文章品質をさらに高めたい場合に活用できる機能です。
Q18. is DeepL free to use?
Yes, DeepL offers a free version that allows you to translate up to 1,500 characters per request without registration. You can also translate up to 3 files (Word, PowerPoint etc. — not PDF) per month for free. For unlimited text translation, PDF support, data privacy protection, and glossary features, DeepL Pro plans start from approximately ¥1,056/month (annual plan). A free trial of DeepL Pro is available, so you can test all Pro features before committing.
