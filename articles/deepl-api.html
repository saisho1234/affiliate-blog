DeepL APIの使い方と料金【2026年】Free/Proの違いと始め方

2026年11月23日 最終更新: 2026年11月23日
小田 健真
ChatGPT・Claude・Geminiなど主要AIを日常的に活用するブロガー。各ツールを実際に試し、使いやすさ・料金・機能をわかりやすく比較・解説しています。

結論

DeepL APIは、自分のプログラムやツールからDeepLの翻訳を呼び出すための開発者向けサービスです。ブラウザで使うDeepL翻訳やDeepL Pro（翻訳ツールのサブスクリプション）とは別の契約として提供されています。まずはFreeプランでAPIキーを取得し、少量で動作を確かめてから、利用量に応じてProプランを検討する流れが一般的です。

  • Freeは月の翻訳文字数に上限がある無料枠（月50万文字までとされる。公式で要確認）
  • Proは基本料金＋使った文字数に応じた従量課金という料金体系とされる（金額は公式で要確認）
  • FreeとProではAPIのエンドポイント（接続先URL）が異なる点に注意
  • 料金・上限・提供条件はDeepL API公式ページで必ず最新情報を確認する

DeepL APIとは？DeepL Proとの違い

DeepL APIは、DeepLの翻訳エンジンをプログラムから利用するための仕組みです。たとえば次のような用途で使われます。

  • 社内チャットや業務システムに翻訳ボタンを組み込む
  • ECサイトの商品説明や、アプリの多言語対応の下訳を自動で作る
  • スプレッドシートやスクリプトで大量のテキストを一括翻訳する
  • 問い合わせメールを自動で翻訳して担当者に回す

混同しやすいのが「DeepL Pro」との違いです。DeepL Proは、ブラウザやアプリで人が翻訳するためのサブスクリプションで、APIはプログラムから呼び出すための別サービスとして案内されています。DeepL Proを契約していても、APIが使い放題になるわけではないと考えておきましょう（契約の扱いは公式で要確認）。人が使う翻訳ツールの料金はDeepL Pro料金プラン比較で整理しています。

APIキーの取得方法

  1. DeepL API公式ページを開き、FreeまたはProのプランを選んで登録する
  2. DeepLのアカウントにログインし、アカウント設定の「APIキー」の画面を開く
  3. 表示されている認証キー（APIキー）をコピーする。必要に応じて新しいキーを発行する

APIキーはパスワードと同じくらい重要な情報です。GitHubなどの公開リポジトリにそのまま書き込むと、第三者に使われて利用枠を消費されたり、Proでは想定外の請求につながったりするおそれがあります。環境変数や秘密情報の管理機能に保存し、ソースコードに直接書かないようにしましょう。

最小コードで翻訳してみる（curl・Python）

ここでは動作確認用の最小限の例を紹介します。仕様は更新されることがあるため、実装時はDeepL APIの公式ドキュメントもあわせて確認してください。YOUR_API_KEY の部分は自分のキーに置き換えます。

curlで試す（Freeプランの例）

curl -X POST 'https://api-free.deepl.com/v2/translate' \
  --header 'Authorization: DeepL-Auth-Key YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{"text": ["Hello, world!"], "target_lang": "JA"}'

成功すると、訳文と検出された翻訳元の言語がJSON形式で返ってきます。Proプランの場合は、URLを https://api.deepl.com/v2/translate に変えます。認証はリクエストヘッダーにキーを入れる方式です。

Pythonで試す（公式ライブラリ）

DeepLはPython向けの公式クライアントライブラリを公開しています。pip install deepl でインストールし、次のように書きます。

import os
import deepl

translator = deepl.Translator(os.environ["DEEPL_API_KEY"])
result = translator.translate_text("Hello, world!", target_lang="JA")
print(result.text)

公式ライブラリを使うと、FreeかProかに応じた接続先の切り替えを自動で行ってくれるため、エンドポイントの書き間違いを防げます。Node.jsなどほかの言語向けのライブラリも用意されています。

よく使うオプション

  • target_lang：翻訳先の言語。英語は EN-US / EN-GB のように地域を指定する形式が推奨されている
  • source_lang：翻訳元の言語。省略すると自動判定。短い文では判定がぶれやすいので、わかっている場合は指定する
  • formality：丁寧さの度合い。対応している言語とプランは公式で要確認
  • 用語集（glossary）：社名や専門用語の訳語を固定する機能。対応する言語の組み合わせは公式で要確認

使用量（文字数）を確認する方法

APIには、当月に使った文字数と上限を確認するための仕組み（usageエンドポイント）があります。Pythonのライブラリなら translator.get_usage() で確認できます。アカウントの管理画面からも使用状況を確認できるので、定期的にチェックする習慣をつけておくと、Freeプランの上限到達やProでの使いすぎを防げます。

なお、ブラウザ版のDeepL無料版の制限（1回あたりログインなし1,500文字／ログイン時5,000文字、月5万文字程度とされる。公式で要確認）とAPIの文字数枠は別物です。ブラウザ版で上限に達した場合の対処はDeepL無料版の上限と解除方法5選を参照してください。

料金の考え方と見積もりのコツ

Proプランは「基本料金＋使った文字数に応じた料金」という考え方とされています。具体的な単価は変更されることがあるため本記事では断定しませんが、見積もりは次の手順で立てると現実的です。

  1. 翻訳したい文章の月間文字数を見積もる：1件あたりの平均文字数×月の件数で概算する
  2. 再翻訳を減らせるか考える：同じ文章を何度も訳す仕組みなら、結果をキャッシュ（保存）して再利用すると文字数を節約できる
  3. Freeで実際の消費量を測る：まずFreeプランで小規模に動かし、usageで実際の消費ペースを確認する
  4. 公式の単価で計算し、上限を設定する：DeepL API公式ページの単価で月額を計算し、利用上限（コスト上限）を設定できる場合は設定しておく

課金対象となる文字数の数え方（空白や記号、HTMLタグの扱いなど）も公式ドキュメントで確認しておくと、想定とのずれを防げます。

はまりやすい注意点

  • エンドポイントの取り違え：FreeのキーでProのURLに接続する（またはその逆）と認証エラーになります。Freeプランのキーは末尾が「:fx」になっているとされ、見分ける目安になります。
  • 英語の指定：翻訳先に「EN」だけを指定すると非推奨やエラーになる場合があるため、EN-USかEN-GBを指定します。
  • レート制限：短時間に大量のリクエストを送ると、一時的に制限されることがあります。エラー時は少し待って再試行する処理を入れておきましょう。
  • HTMLやXMLの翻訳：タグを含む文章をそのまま送るとタグが崩れることがあります。タグを扱うオプションの有無を公式ドキュメントで確認してください。
  • 機密情報の扱い：個人情報や顧客データを送る場合は、データの扱いに関する公式の説明と社内ルールを必ず確認します。
  • 訳文の品質確認：APIは自動で大量に訳せる反面、誤訳にも気づきにくくなります。公開前に人が確認する工程を入れておくのが安全です。DeepLが苦手な文章はDeepLの翻訳精度は？で解説しています。

まとめ

DeepL APIは、まずFreeプランでキーを取得し、curlや公式ライブラリで動作を確認するところから始めるのがおすすめです。FreeとProではエンドポイントが異なる点、APIはDeepL Proとは別の契約である点を押さえておけば、大きくつまずくことはありません。料金や上限は変わることがあるため、本番運用の前に公式の最新情報で見積もりを立ててください。プログラムを書かずにファイルを訳したい場合はDeepLでWord・PDF・PowerPointを翻訳する方法、基本操作はDeepLの使い方をご覧ください。

よくある質問（FAQ）

DeepL APIは無料で使えますか？
Freeプランなら無料で使えます。月に翻訳できる文字数に上限があり、月50万文字までとされています。上限や提供条件は変更される可能性があるため、公式で確認してください。
DeepL API Proの料金はいくらですか？
基本料金に加えて、使った文字数に応じて課金される料金体系とされています。単価は変更されることがあるため、当サイトでは金額を断定していません。公式のAPI料金ページで確認してください。
DeepL Proを契約していればAPIも使えますか？
DeepL Pro（翻訳ツールのサブスクリプション）とDeepL APIは別のサービスとして案内されています。APIを使うにはAPIのプランへの登録が必要です。詳細は公式で確認してください。
APIで認証エラーが出ます。
FreeのキーでProのエンドポイントに接続している、またはその逆の可能性があります。Freeはapi-free.deepl.com、Proはapi.deepl.comです。キーの貼り付けミスや、ヘッダーの書式も確認してください。
FreeとProで翻訳の品質は違いますか？
翻訳エンジンの品質に差があるという案内は確認できていません。主な違いは利用できる文字数、料金、データの扱い、利用できる機能です。詳細は公式で確認してください。
プログラミングなしでDeepLを大量に使う方法はありますか？
ブラウザ版やデスクトップアプリのファイル翻訳を使えば、WordやPDFをまとめて訳せます。量が多い場合はDeepL Proの利用も検討してください。
