DeepLの上限の種類と仕組みを完全解説

DeepLの「上限に達しました」エラーには複数の種類があります。どの制限に引っかかっているかを把握することが、正しい対処法を選ぶ第一歩です。

制限の種類 内容 リセット
Web翻訳上限 1回1,500文字まで 即時（次の翻訳で1,500文字）
ファイル翻訳上限 月3ファイルまで 毎月1日にリセット
短時間アクセス制限 短時間に大量翻訳すると一時制限 数分〜数時間で自動解除
API利用上限 無料版 月50万文字 毎月リセット

最も多くのユーザーが遭遇するのは「1回1,500文字」の制限と「短時間アクセス制限」です。それぞれ対処法が異なるため、以下で詳しく解説します。

DeepL無料版の翻訳上限とは

DeepLは世界トップクラスの翻訳精度を誇るAI翻訳サービスです。無料で利用できる点が大きな魅力ですが、無料版には明確な利用制限が設けられています。まず制限の全体像を正確に把握しましょう。

DeepL無料版の制限一覧（2026年時点）

  • 1回あたりの翻訳文字数：1,500文字まで
  • ファイル翻訳：月3ファイルまで（PDF・Word・PowerPoint・テキスト）
  • 翻訳言語数：30言語以上対応（無料版でも同様）
  • 用語集（Glossary）機能：利用不可（Pro専用）
  • 翻訳メモリ：利用不可（Pro専用）
  • APIアクセス：別途「DeepL API Free」で月50万文字まで（開発者向け）
  • 同時利用デバイス：制限あり
  • 月間翻訳量：公式に明示なし（短時間大量翻訳で一時制限がかかる場合あり）

最も頻繁に問題になるのが「1回あたり1,500文字」の制限です。日本語の一般的なビジネスメールが300〜500字、英語の論文要旨が500〜1,000字程度なので、1文書をそのまま貼り付けられないケースが多く発生します。

また、ファイル翻訳の月3ファイル制限も実務利用では頻繁に上限に達します。英語の契約書・技術仕様書・マニュアルを月に複数件翻訳する業務では、3ファイルで不足することがほとんどです。

月間制限について

DeepLの無料版には1,500文字/回の制限とは別に、短時間に大量の翻訳を行った場合に「一時的な利用制限」がかかることがあります。この制限は時間経過とともに自動解除されますが、具体的なリセット時間は公式に公表されていません。

一般的には数時間〜1日程度で制限が解除されるとユーザーから報告されています。即時に上限を解除したい場合は、後述するDeepL Proへのアップグレードが必要です。

上限に達したときのエラーメッセージと対処法

DeepLの無料版で上限に達した場合、いくつかのパターンでエラーや制限の案内が表示されます。それぞれの対処法を解説します。

パターン1：テキスト翻訳で1,500文字を超えた場合

入力テキストが1,500文字を超えると、翻訳ボタンがグレーアウトまたは「文字数が超えています」旨のメッセージが表示されます。

対処法：

  • テキストを1,500文字以内に分割して複数回に分けて翻訳する
  • DeepL Proにアップグレードして文字数制限を撤廃する
  • 段落ごとに翻訳してあとで結合するワークフローを採用する

パターン2：ファイル翻訳で月3ファイルの上限に達した場合

「今月のファイル翻訳の上限に達しました」または「翻訳できるファイル数の上限に達しました」というメッセージが表示されます。

対処法：

  • 翌月のリセットを待つ（月初に3ファイル分の枠がリセットされる）
  • ファイルをコピー＆ペーストでテキストとして取り出し、テキスト翻訳を活用する（ファイル枠を消費しない）
  • DeepL Proにアップグレードしてファイル翻訳上限を解除する

パターン3：短時間大量翻訳による一時制限

「しばらく時間をおいてから再試行してください」のようなメッセージが表示され、翻訳が一時的に利用できなくなる場合があります。

対処法：

  • 30分〜数時間待ってから再試行する
  • 翻訳の間隔を空けてゆっくり使う習慣をつける
  • 即時に解除が必要な業務用途はDeepL Proに移行する

DeepLの上限に達したときの対処法【4選】

「DeepL 無料でご利用いただける上限に達しました」と表示されたとき、状況に応じた4つの解決策があります。

解決策1：時間をおいて再試行する

短時間アクセス制限の場合、30分〜数時間待つと自動解除されます。ファイル翻訳の月3件制限は翌月1日にリセットされます。急ぎでなければ最もシンプルな方法です。

解決策2：テキストを1,500文字以下に分割して翻訳する

長い文章を段落やセクションごとに分割し、複数回に分けて翻訳します。翻訳後に結合すれば大きな文書も対応可能です。WordやPDFのテキストをコピー＆ペーストすれば、ファイル翻訳の枠も消費しません。

解決策3：Google翻訳で一時的に代用する

Google翻訳は文字数制限が事実上なく、無料で100言語以上に対応しています。DeepLが使えない間の一時的な代用として活用できます。ただし翻訳品質はDeepLより劣る場合があります。

解決策4：DeepL Proにアップグレードする（根本的解決）

すべての制限を根本から解除できる唯一の方法です。月に10回以上制限に達する場合は、時間節約の観点からもProへの移行がコスパ良い選択です。詳しくは次のセクションで解説します。

重要：複数アカウント作成は利用規約違反の可能性あり

制限を回避するために複数のアカウントを作成して使い回す行為は、DeepLの利用規約違反になる可能性があります。アカウント停止のリスクもあるため、正規の方法（DeepL Proへの移行）で対処することを強くおすすめします。

DeepL Proで上限を完全に解除する方法

DeepLの翻訳上限を根本的に解除する唯一の方法は、DeepL Proにアップグレードすることです。時間経過による一時的な制限解除を除けば、無料版のままで上限を引き上げる方法はありません。

DeepL Proで解除できる制限一覧

  • テキスト翻訳：1,500文字/回の制限 → 実質無制限
  • ファイル翻訳：月3ファイル → 月5〜100ファイル（プランによる）
  • 短時間アクセス制限：あり → なし
  • 用語集（Glossary）：利用不可 → 利用可能
  • 入力テキストの学習利用：あり → なし（機密情報も安全）

料金の目安：Starterプランは年払いで月1,056円〜。月に10回以上制限に達するなら、時間節約の観点からも十分元が取れます。まず30日間の無料トライアルで試してから継続を判断できます。

上限を気にせず使うためのコツ（無料ユーザー向けTips）

すぐにProに移行しない場合でも、工夫次第で無料版の制限を最小限に抑えることができます。実践的なTipsを紹介します。

Tips 1：1,500文字を超える文書は段落ごとに分割して翻訳する

長文を無理にまとめて貼り付けようとすると制限に引っかかります。段落・セクションごとに分割して翻訳し、あとで結合するワークフローを採用しましょう。英語論文や契約書など構造が明確な文書では、見出し単位で分割するのが効率的です。

Tips 2：ファイル翻訳の枠はPDFなど本当に必要な場合だけ使う

月3ファイルの枠を温存するため、テキストとして取り出せる文書（Word・テキストファイル）はコピー＆ペーストでテキスト翻訳を活用します。ファイル翻訳枠は、テキストでは対応できないPDFや書式が複雑な文書に限定して使うのが賢い使い方です。

Tips 3：翻訳結果を保存・再利用して同じ文章を何度も翻訳しない

一度翻訳した内容はテキストとして保存しておきましょう。同じ文章・フレーズを繰り返し翻訳する作業は制限の無駄遣いです。よく使うフレーズの翻訳はメモに残しておくと繰り返し翻訳が不要になります。

Tips 4：Google翻訳と使い分ける

Google翻訳は実質的に文字数制限がなく、短いフレーズや単語の確認には十分です。高品質な翻訳が必要な場面（提出書類・公式文書・メール返信）ではDeepL、大まかな内容把握や単語確認ではGoogle翻訳を使い分けることでDeepLの無料枠を温存できます。

Tips 5：DeepL拡張機能（ブラウザプラグイン）を活用する

Chrome・Firefox向けのDeepL拡張機能を使うと、Webページ上のテキストを選択して右クリックから翻訳できます。コピー＆ペーストの手間が省けるため、1,500文字以内の短い文章を効率よく翻訳するのに役立ちます。拡張機能自体は無料で利用できます。

Tips 6：翻訳する時間帯を分散させる

短時間に集中して大量翻訳すると一時制限がかかりやすくなります。1日を通して翻訳作業を分散させることで、一時的な利用制限を受けにくくなります。

よくある質問（FAQ）15問

DeepL無料版の翻訳上限は何文字ですか？
DeepL無料版の1回あたりの翻訳上限は1,500文字です。月間の累計制限は公式に明示されていませんが、短時間に大量翻訳を行うと一時的な制限がかかる場合があります。
DeepLで「上限に達しました」と表示されたらどうすればいいですか？
しばらく時間をおいてから再試行するか、DeepL Proにアップグレードすることで解除できます。無料版の制限はリセット周期があり、時間をおくと再び使えるようになる場合があります。
DeepL無料版でファイルを翻訳することはできますか？
無料版でもファイル翻訳は可能ですが、月3ファイルまでの制限があります。対応ファイル形式はPDF・Word・PowerPoint・テキストファイルです。4ファイル以上翻訳するにはDeepL Proが必要です。
DeepL Proにアップグレードすると上限は完全になくなりますか？
DeepL ProのStarter・Advanced・Ultimateプランでは、ウェブ翻訳は実質無制限になります（API利用は別途従量課金）。ファイル翻訳もプランに応じた上限が設けられますが、業務利用には十分な量です。
DeepL Proの料金はいくらですか？
2026年時点の参考価格は、Starterプランが月約¥1,000〜（1名・個人向け）、Advancedプランが月約¥3,000〜（チーム向け）、Ultimateプランが月約¥6,000〜（大量翻訳・API連携向け）です。最新料金はDeepL公式サイトでご確認ください。
DeepLの上限をリセットする方法はありますか？
無料版の制限は時間経過でリセットされる仕組みです（日次・月次リセット）。即時に上限を解除したい場合はDeepL Proへのアップグレードが唯一の方法です。アカウントを複数作成して回避しようとすると利用規約違反になる場合があります。
DeepL無料版とProの翻訳品質に差はありますか？
基本的な翻訳エンジンは同じですが、DeepL ProではAIによるスタイル調整・用語集機能（専門用語の統一）・翻訳メモリ機能が利用できるため、業務用途では品質と一貫性がさらに向上します。
DeepLのAPI上限と通常利用の上限は別ですか？
はい、ウェブサイト・アプリでの通常翻訳と、DeepL APIの利用枠は別管理です。API利用は無料版（DeepL API Free）でも月50万文字まで利用できますが、開発者向けです。一般ユーザーのウェブ利用とは別物と考えてください。
学生・個人が業務以外で使う場合、無料版で十分ですか？
英語論文の読解・メールの翻訳確認・海外サイトの記事チェックなど、1回1,500文字以内の用途であれば無料版で十分なケースが多いです。ただしファイル翻訳を月4本以上行う場合はProが必要になります。
DeepL以外で制限なく使える翻訳ツールはありますか？
Google翻訳は無料版でも文字数制限が事実上なく、ウェブ翻訳には広く使われています。ただし翻訳品質ではDeepLの方が自然な訳文を生成すると評価されています。用途に応じて使い分けるのが現実的です。詳しくは AI翻訳ツール比較記事 をご覧ください。
DeepLの上限はいつリセットされますか？
制限の種類によって異なります。1回1,500文字の制限は「次の翻訳」で即座にリセットされます（1回の上限であるため）。ファイル翻訳の月3件制限は毎月1日にリセットされます。短時間に大量翻訳したことによる一時制限は、数分〜数時間で自動解除されます。
DeepL Proにすると上限は完全になくなりますか？
はい、Proにアップグレードするとテキスト翻訳は実質無制限になります。ファイル翻訳もプランに応じた上限（Starter: 月5件、Advanced: 月20件、Ultimate: 月100件）に大幅拡張されます。短時間アクセス制限もなくなります。
「DeepL 無料でご利用いただける上限に達しました」の英語メッセージは？
英語では "You've reached the free usage limit." または "The free usage limit has been reached." と表示されます。英語インターフェースを使用している場合はこのメッセージが出ます。対処法は日本語版と同じです。
