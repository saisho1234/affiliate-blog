最も多くのユーザーが遭遇するのは「1回1,500文字」の制限と「短時間アクセス制限」です。それぞれ対処法が異なるため、以下で詳しく解説します。

DeepL無料版の翻訳上限とは

DeepLは世界トップクラスの翻訳精度を誇るAI翻訳サービスです。無料で利用できる点が大きな魅力ですが、無料版には明確な利用制限が設けられています。まず制限の全体像を正確に把握しましょう。

DeepL無料版の制限一覧（2026年時点）

  • 1回あたりの翻訳文字数：1,500文字まで
  • ファイル翻訳：月3ファイルまで（PDF・Word・PowerPoint・テキスト）
  • 翻訳言語数：30言語以上対応（無料版でも同様）
  • 用語集（Glossary）機能：利用不可（Pro専用）
  • 翻訳メモリ：利用不可（Pro専用）
  • APIアクセス：別途「DeepL API Free」で月50万文字まで（開発者向け）
  • 同時利用デバイス：制限あり
  • 月間翻訳量：公式に明示なし（短時間大量翻訳で一時制限がかかる場合あり）

最も頻繁に問題になるのが「1回あたり1,500文字」の制限です。日本語の一般的なビジネスメールが300〜500字、英語の論文要旨が500〜1,000字程度なので、1文書をそのまま貼り付けられないケースが多く発生します。

また、ファイル翻訳の月3ファイル制限も実務利用では頻繁に上限に達します。英語の契約書・技術仕様書・マニュアルを月に複数件翻訳する業務では、3ファイルで不足することがほとんどです。

月間制限について

DeepLの無料版には1,500文字/回の制限とは別に、短時間に大量の翻訳を行った場合に「一時的な利用制限」がかかることがあります。この制限は時間経過とともに自動解除されますが、具体的なリセット時間は公式に公表されていません。

一般的には数時間〜1日程度で制限が解除されるとユーザーから報告されています。即時に上限を解除したい場合は、後述するDeepL Proへのアップグレードが必要です。

上限に達したときのエラーメッセージと対処法

DeepLの無料版で上限に達した場合、いくつかのパターンでエラーや制限の案内が表示されます。それぞれの対処法を解説します。

パターン1：テキスト翻訳で1,500文字を超えた場合

入力テキストが1,500文字を超えると、翻訳ボタンがグレーアウトまたは「文字数が超えています」旨のメッセージが表示されます。

対処法：

  • テキストを1,500文字以内に分割して複数回に分けて翻訳する
  • DeepL Proにアップグレードして文字数制限を撤廃する
  • 段落ごとに翻訳してあとで結合するワークフローを採用する

パターン2：DeepLファイル翻訳の上限に達した場合（月3ファイル制限）

「今月のファイル翻訳の上限に達しました」または「翻訳できるファイル数の上限に達しました」というメッセージが表示されます。ファイル翻訳の制限についてさらに詳しく知りたい方は「DeepLファイル翻訳の上限と対処法」もあわせてご覧ください。

対処法：

  • 翌月のリセットを待つ（月初に3ファイル分の枠がリセットされる）
  • ファイルをコピー＆ペーストでテキストとして取り出し、テキスト翻訳を活用する（ファイル枠を消費しない）
  • DeepL Proにアップグレードしてファイル翻訳上限を解除する

パターン3：短時間大量翻訳による一時制限

「しばらく時間をおいてから再試行してください」のようなメッセージが表示され、翻訳が一時的に利用できなくなる場合があります。

対処法：

  • 30分〜数時間待ってから再試行する
  • 翻訳の間隔を空けてゆっくり使う習慣をつける
  • 即時に解除が必要な業務用途はDeepL Proに移行する

DeepL「上限に達しました」を解除する5つの方法

「DeepL 無料でご利用いただける上限に達しました」と表示されたとき、すぐに試せる解除方法を5つ紹介します。上から順に手軽な方法です。

解決策1：Cookie・キャッシュを削除する（最も手軽）

DeepL無料版はブラウザのCookieで利用状況を管理しています。Cookieとキャッシュを削除することで、利用カウントがリセットされ、一時的に制限が解除される場合があります。

手順（Chromeの場合）：

  1. Chromeの設定 → 「プライバシーとセキュリティ」→「閲覧履歴データの削除」を開く
  2. 「Cookieと他のサイトデータ」「キャッシュされた画像とファイル」にチェックを入れる
  3. 「データを削除」をクリック → DeepLを再度開く
メリット：最も簡単で即効性がある。ブラウザの操作だけで完了
デメリット：他サイトのログイン情報も消える場合あり。一時的な対処に過ぎない

解決策2：シークレットモード（プライベートブラウズ）を使う

ブラウザのシークレットモード（Chromeなら「Ctrl+Shift+N」）でDeepLを開くと、Cookieが引き継がれないため制限がリセットされた状態で利用できます。

メリット：Cookie削除の手間が不要。通常ブラウザのログイン情報に影響しない
デメリット：毎回シークレットモードを開く必要がある。翻訳履歴が保存されない

解決策3：別のブラウザで開く

Chrome→Microsoft Edge→Firefox→Braveなど、普段使っていないブラウザでDeepLを開くだけで制限を回避できます。各ブラウザが別のCookieを管理しているためです。

メリット：設定変更不要。複数ブラウザを切り替えるだけ
デメリット：ブラウザの数に上限がある。根本解決にはならない

解決策4：時間をおいて再試行する

短時間アクセス制限の場合、30分〜数時間待つと自動解除されます。ファイル翻訳の月3件制限は翌月1日にリセットされます。急ぎでなければ最もシンプルな方法です。

メリット：何もしなくてよい。確実に解除される
デメリット：急ぎの翻訳には対応できない。数時間かかる場合もある

解決策5：DeepL Proにアップグレードする（根本的解決・おすすめ）

すべての制限を根本から解除できる唯一の方法です。30日間の無料トライアルがあるため、まず無料で試してから継続するか判断できます。月に5回以上制限に達する場合は、時間節約の観点からもProへの移行がコスパ良い選択です。

メリット：文字数制限が完全に解除される。セキュリティ強化・用語集機能も使える
デメリット：月額約1,000円〜の費用がかかる（30日無料トライアルあり）

重要：複数アカウント作成は利用規約違反の可能性あり

制限を回避するために複数のアカウントを作成して使い回す行為は、DeepLの利用規約違反になる可能性があります。アカウント停止のリスクもあるため、正規の方法（DeepL Proへの移行）で対処することを強くおすすめします。

「使っていないのに上限に達しました」DeepLで表示される原因と対処法

DeepLをほとんど使っていないのに「上限に達しました」エラーが出る——これは多くのユーザーが経験する不思議な現象です。実はこれには明確な原因があります。

原因①：共有IPアドレスによる誤判定

DeepL無料版はIPアドレス単位で利用量を管理しています。学校・図書館・会社・カフェのWi-Fiなど、同じIPアドレスを多数のユーザーが共有しているネットワークでは、他のユーザーの翻訳量が合算されてしまい、自分はほとんど使っていないのに制限に達したように見えることがあります。

対処法：スマホのモバイルデータ通信（テザリング）や、別のWi-Fiネットワークに切り替えて試してみてください。自分専用のIPアドレスに変わることでエラーが解消するケースが多いです。

原因②：ブラウザ拡張機能が自動翻訳していた

ChromeやFirefoxにDeepL拡張機能をインストールしている場合、ページを開くたびに自動で翻訳リクエストが送られていることがあります。意識せずに大量の翻訳リクエストを消費していることが原因です。

対処法：拡張機能の「自動翻訳」設定をオフにするか、拡張機能を一時的に無効化してください。

原因③：短時間の大量アクセスによる一時制限

短時間に連続して翻訳ボタンを押した場合、総文字数が少なくても「短時間アクセス制限」が発動します。これはボット対策の自動判定によるものです。

対処法：数分〜数十分待てば自動解除されます。翻訳後は少し間を置いてから次の翻訳を行う習慣をつけましょう。

「使っていないのに上限エラー」のチェックリスト

  • 公共Wi-Fi（学校・図書館・カフェ）を使っている → スマホのモバイル回線に切り替える
  • DeepL拡張機能をインストールしている → 自動翻訳設定をオフにする
  • 短時間に連続翻訳した → 数分待ってから再試行する

Tips 1：1,500文字を超える文書は段落ごとに分割して翻訳する

長文を無理にまとめて貼り付けようとすると制限に引っかかります。段落・セクションごとに分割して翻訳し、あとで結合するワークフローを採用しましょう。英語論文や契約書など構造が明確な文書では、見出し単位で分割するのが効率的です。

Tips 2：ファイル翻訳の枠はPDFなど本当に必要な場合だけ使う

月3ファイルの枠を温存するため、テキストとして取り出せる文書（Word・テキストファイル）はコピー＆ペーストでテキスト翻訳を活用します。ファイル翻訳枠は、テキストでは対応できないPDFや書式が複雑な文書に限定して使うのが賢い使い方です。

Chrome・Firefox向けのDeepL拡張機能を使うと、Webページ上のテキストを選択して右クリックから翻訳できます。コピー＆ペーストの手間が省けるため、1,500文字以内の短い文章を効率よく翻訳するのに役立ちます。拡張機能自体は無料で利用できます。
