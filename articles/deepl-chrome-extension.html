DeepL Chrome拡張機能は、Webページ上の任意のテキストをその場でDeepL翻訳できる公式Chrome拡張です。ブラウジング中に英語の記事・ドキュメント・メールを読む際に、わざわざDeepL公式サイトを開く必要がなくなります。

DeepL Chrome拡張でできること

  • テキストを選択するだけでポップアップ翻訳
  • Ctrl+Shift+Eでページ全体を一発翻訳
  • 翻訳結果を1クリックでコピー
  • 翻訳先言語の固定設定（毎回選択不要）
  • 右クリックメニューから「DeepLで翻訳」

DeepLの翻訳品質はGoogle翻訳と比べて「より自然な日本語」と評価されています。特にビジネス文書・技術ドキュメント・論文の翻訳では文脈を踏まえた表現が得られるため、英語を頻繁に読む方に強くおすすめできます。DeepLの詳しい評価はDeepLレビュー記事もご覧ください。

インストール方法（3ステップ）

DeepL Chrome拡張のインストールは3ステップ・約1分で完了します。

ステップ1：Chromeウェブストアにアクセス

Chromeブラウザを開き、アドレスバーに「chrome.google.com/webstore」と入力してChromeウェブストアにアクセスします。または検索エンジンで「DeepL Chrome拡張」と検索し、公式のChrome Web Storeページにアクセスします。

ステップ2：「Chromeに追加」をクリック

Chromeウェブストアの検索窓に「DeepL」と入力して検索します。「DeepL: AI翻訳ツール」という公式拡張機能が表示されるので、「Chromeに追加」ボタンをクリックします。確認ダイアログが表示されたら「拡張機能を追加」をクリックして完了です。

ステップ3：アドレスバー右側のアイコンを確認

インストール完了後、Chromeのアドレスバー右側にDeepLのアイコン（青い「D」マーク）が表示されます。表示されない場合は、パズルのピースアイコン（拡張機能メニュー）をクリックして「DeepL」の横にある「ピン止め」アイコンをクリックすると常時表示されます。

基本的な使い方（選択翻訳・ページ翻訳）

使い方①：テキスト選択翻訳

DeepL Chrome拡張の最も基本的な使い方です。

  1. 翻訳したいテキストをマウスでドラッグして選択する
  2. 選択テキストの近くにDeepLのポップアップアイコンが表示される
  3. アイコンをクリックすると翻訳結果がポップアップで表示される
  4. 右上のコピーアイコンをクリックで翻訳結果をコピー
  5. 「DeepLで開く」をクリックするとDeepL公式サイトで詳細翻訳も可能

ポイント：テキストを選択後、すぐにアイコンが表示されない場合は、選択したまま少し待つか、右クリックメニューから「DeepLで翻訳」を選択してください。

使い方②：ページ全体翻訳

英語のWebページ全体を日本語に翻訳したい場合は、ショートカットキーを使います。

  1. 翻訳したいページを開く
  2. Ctrl+Shift+E（WindowsはCtrl、MacはCmd）を押す
  3. ページ全体がDeepL翻訳された日本語に切り替わる
  4. 元の英語に戻すには再度Ctrl+Shift+Eを押す（トグル切り替え）

ページ翻訳はGoogle翻訳のChrome内蔵翻訳よりも自然な日本語になるため、英語の技術ドキュメント・海外ニュース・論文を読む際に特に効果を発揮します。

使い方③：右クリックメニューから翻訳

テキスト選択後にポップアップが出ない場合や、素早く翻訳したい場合は右クリックメニューを使います。

  1. 翻訳したいテキストを選択する
  2. 右クリックしてコンテキストメニューを開く
  3. 「DeepLで翻訳」または「選択テキストをDeepLで翻訳」を選択
  4. DeepL公式サイトが新しいタブで開き、翻訳結果が表示される

便利な設定とショートカット

翻訳先言語の固定設定

毎回翻訳先言語を選択する手間を省けます。

  1. アドレスバー右のDeepLアイコンをクリック
  2. 「設定」（歯車アイコン）をクリック
  3. 「翻訳先の言語」で「日本語」を選択して保存
  4. 以降は翻訳時に毎回言語選択が不要になる

ポップアップアイコンの表示/非表示切り替え

テキスト選択時に自動でポップアップが表示されるのが邪魔な場合は、設定からオフにできます。DeepLアイコン→設定→「テキスト選択時にアイコンを表示」をオフにすると、ポップアップが出なくなり、右クリックメニューからのみ翻訳できます。

無料版と有料版の違い

DeepL Chrome拡張は無料でも主要機能が使えますが、翻訳量の多い方には有料版（DeepL Pro）が必要な場合があります。

日常的なWebブラウジングや月5,000文字以内の翻訳なら、無料版で十分です。毎日大量のビジネス文書を翻訳する場合や、機密情報を扱う場合はDeepL Proを検討しましょう。DeepLの無料制限についてはDeepL無料制限の詳細もご参照ください。

よくあるトラブルと解決策

トラブル1：ポップアップが表示されない

原因と対処法：

  • 拡張機能が無効になっている → アドレスバー右のDeepLアイコンをクリックして有効を確認
  • サイトへのアクセス権限が不足 → アイコン右クリック→「サイトへのアクセスを管理」→「すべてのサイト」に変更
  • Chromeを再起動していない → Chromeを完全に閉じて再起動

トラブル2：ページ翻訳のショートカット（Ctrl+Shift+E）が動かない

対処法：

  • chrome://extensions/shortcuts にアクセスして、DeepLのショートカットを手動で再設定する
  • 他の拡張機能と競合している可能性があるため、ショートカットを別のキーに変更する

トラブル3：月5,000文字の制限に達した

翻訳がブロックされ制限到達メッセージが表示されます。対処法は以下の通りです。

  • 翌月まで待つ（無料枠は月次リセット）
  • DeepL公式サイトでの翻訳を使う（別カウント）
  • DeepL Proにアップグレードして制限を解除する

トラブル4：PDFが翻訳できない

ローカルに保存したPDFはChrome拡張では翻訳できません。DeepL公式サイト（deepl.com）のファイルアップロード機能をご利用ください。ブラウザで表示したオンラインPDF（URL付き）なら拡張機能で翻訳可能です。

よくある質問（FAQ）

DeepL Chrome拡張は無料で使えますか？
はい、基本機能は無料で使えます。月5,000文字まで翻訳無料です。それ以上使う場合はDeepL Proへのアップグレードが必要です。
DeepL Chrome拡張のインストール方法を教えてください
Chromeウェブストアで「DeepL」を検索し、「Chromeに追加」をクリックするだけです。インストールは1分以内に完了します。
ページ全体を翻訳するショートカットキーは？
Ctrl+Shift+E（Windowsの場合）/ Cmd+Shift+E（Mac）でページ全体を翻訳できます。再度押すと元の言語に戻ります。
テキストを選択すると翻訳ボタンが出ない
拡張機能が有効かアドレスバー右の拡張機能アイコンを確認してください。サイトによってはアイコン右クリック→「DeepLで翻訳」を使う方法も有効です。
DeepL拡張でPDFは翻訳できますか？
ブラウザで直接表示したPDFのみ対応しています。ローカルに保存したPDFはDeepL公式サイト（deepl.com）でのファイルアップロード翻訳をご利用ください。
DeepL拡張とGoogle翻訳拡張の違いは？
DeepLは文脈を考慮した自然な翻訳が得意です。技術文書・ビジネス文章はDeepLの方が高精度です。Google翻訳は多言語対応に強みがあります。
翻訳結果をコピーする方法は？
ポップアップ右上のコピーアイコンをクリックするか、翻訳テキストを選択してCtrl+Cでコピーできます。
DeepL拡張でプライバシーは大丈夫？
翻訳テキストはDeepLサーバーに送信されます。機密情報の翻訳にはDeepL Pro（データ保護オプション）を推奨します。無料版では送信データの一部が品質向上に使用される場合があります。
スマホ版Chrome（Android/iOS）でも使えますか？
Chrome拡張機能はスマホ版Chromeには対応していません。スマホでの翻訳にはDeepL公式アプリをご利用ください。
無料プランの月5,000文字制限を超えたらどうなる？
翻訳がブロックされ、DeepL Proへのアップグレードを促すメッセージが表示されます。DeepL Proにアップグレードすると文字数無制限で利用できます。
